# POS System Frontend

Frontend web del sistema POS, desarrollado con React, TypeScript y Vite.

## Tecnologías

- React
- TypeScript
- Vite
- ESLint

## Requisitos

- Node.js 24
- npm 11

## Instalación

```bash
npm install
```

## Comandos disponibles

Iniciar el servidor de desarrollo:

```bash
npm run dev
```

Revisar el código con ESLint:

```bash
npm run lint
```

Comprobar TypeScript y generar la versión de producción:

```bash
npm run build
```

Los archivos de producción se generan en el directorio `dist/`.
